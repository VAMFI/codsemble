# Support

Codsemble is community-supported.

Use the repository issue tracker for:

- reproducible bugs using synthetic or public fixtures;
- documentation problems;
- feature proposals;
- compatibility reports that identify Codex, Node.js, and operating-system
  versions.

Use GitHub Discussions, when enabled, for setup questions and design ideas.
Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Before requesting support:

1. Run `$team-doctor` in the affected workspace.
2. Remove secrets and absolute personal paths from the report.
3. State whether the evidence is static validation, a fixture/simulation, or a
   fresh Codex runtime observation.
4. Include the smallest reproducible example.

Maintainers cannot recover deleted data, access private repositories, debug
personal credentials, or guarantee compatibility with unpublished Codex
features.
