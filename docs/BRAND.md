# Codesemble brand guide

Codesemble turns repository evidence into the smallest capable native Codex
team. The brand should always make that transformation feel precise, calm, and
reviewable.

## Brand idea

- **Name:** Codesemble
- **Pronunciation:** code-sem-bull
- **Meaning:** Code + assemble
- **Category:** repository-aware team builder for Codex
- **Core promise:** Evidence in. Native team out.

Use the full name `Codesemble` in prose. Use the uppercase `CODESEMBLE` wordmark
only inside approved visual assets or when a display treatment calls for it.
Lowercase machine identifiers—including the current repository, package, plugin,
and state-directory slug—remain `codsemble` for compatibility.

## Positioning

Preferred one-line description:

> Codesemble audits a repository and assembles the smallest capable native Codex team.

Preferred short tagline:

> The repository-aware team builder for Codex.

Codesemble is not an agent swarm, a hosted orchestration runtime, or a promise
that 111 agents will run simultaneously. The catalog is a search space;
Codesemble's value is choosing a small, evidence-backed team and compiling it
into reviewable project configuration.

## Voice

- **Clear:** explain the outcome before the mechanism.
- **Calm:** prefer precise claims over futuristic hype.
- **Human:** say “your repository” and “your team,” not “autonomous workforce.”
- **Evidence-led:** distinguish recommendations, previews, structural tests, and runtime proof.
- **Safe by default:** make confirmation and reversibility visible without fear-based language.

Prefer:

> Audit your repository. Assemble the smallest capable Codex team.

Avoid:

> Unleash 111 autonomous agents instantly.

## Visual system

The primary metaphor is a transparent prism:

- repository evidence enters as varied fragments;
- the prism represents diagnosis and deterministic compilation;
- native project artifacts and a small team emerge as distinct outputs.

The visual language uses deep midnight navy, electric cyan, violet, cool white,
and one restrained coral accent. Glass, precision geometry, controlled light,
and generous negative space communicate trustworthy engineering.

Avoid robot imagery, humanoid agent avatars, crowded dashboards, generic node
clouds, cyber-security clichés, and neon overload.
