What does “preview” mean?

The plan names roles, instructions, configuration, and every managed path. Apply rechecks the exact plan and refuses stale project state.

Why is there a 111-entry catalog?

It is a library of reusable capability primitives, not a roster or team-size target. Codesemble dynamically selects only roles justified by the repository and goal.
