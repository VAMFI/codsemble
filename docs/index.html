You keep the wheel

The primary thread coordinates. You decide.

Generated specialists are available capabilities, not an always-running swarm. The primary Codex thread delegates bounded work, reconciles evidence, and owns the final result.

A common misconception

111 is a library, not a roster.

The catalog contains reusable capability primitives. Codesemble selects only roles justified by your project and goal; installed roles and active workers remain separate.
